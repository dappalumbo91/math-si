# math-si

A local dial for FSOT formulas. Gemma 4 E4B proposes. The pinned engine
computes. A published uncertainty scores. Lean 4 checks a formal
statement. An append-only ledger records the try.

The base model is [google/gemma-4-E4B-it](https://huggingface.co/google/gemma-4-E4B-it),
Apache License 2.0. This repository holds the dial and the LoRA adapters.
It does not hold the base weights. See `NOTICE`.

Start with `RESUME.md`. That file is the pickup note for the next session:
what was trained, what passed a published bar, and what is still open.

The live dial loads `adapter/` (epoch 1). The scored passes through
2026-10-19 are in `adapter-epoch7/`. Nothing in the ledger has `send: true`.

The mathematical hub at `FSOT-2.1-Lean` is read by this project and is not
modified from here. Pin AEB2AD stays the engine pin.
